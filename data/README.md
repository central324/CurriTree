# 교육과정 데이터

`data/curricula/` 폴더의 JSON 파일 하나가 교육과정 하나입니다. 서버는 시작할 때 이 폴더를 읽고 아래 API로 제공합니다.

| API | 내용 |
| --- | --- |
| `GET /api/departments` | 학과 목록과 학과별 교육과정 목록 |
| `GET /api/curriculum/:dept` | 학과의 기본 교육과정 JSON (`?curriculumId=`로 선택 가능) |

형식은 `docs/CONTRACT_CHECKLIST.md` 2절을 따릅니다. 계약을 어긴 파일이 하나라도 있으면 서버 로그에 오류가 표시되고 조회 API는 500을 반환합니다. `npm test`로 미리 확인할 수 있습니다.

## 현재 등록된 교육과정

### `ce-2023.json` — 컴퓨터정보공학부 (2023학번 기준, 이슈 #15)

- 과목·학기·이수구분·학점: [교과과정표(2023학년도)](https://ce.kw.ac.kr/program/process.php) 42과목·113학점. 과거 과목명은 `aliases`
- `공학설계입문`: 표에는 없지만 이수체계도의 필수 선수(→ 객체지향프로그래밍설계)라 포함. 이수구분 `unknown`, 학점은 기존 값(3)
- 선수·연계 관계: [이수체계도](https://ce.kw.ac.kr/engineering_certify/subject.php)
  - `hardPrerequisiteIds`: 필수 선후수(빨간 화살표). 체계도에 없거나 선수 과목이 데이터에 없으면 `null`
  - `recommendedPreviousIds`: 추천 선후수(검은 화살표) + 같은 과목명 1 → 2
  - `linkedCourseIds`: 설계(이론)↔실습·실험 짝 5쌍
- 진로 트랙 태그: 26년 전공 로드맵의 3개 트랙 (로드맵에 없는 `인공지능프로그래밍`은 `[]`)
- `requiredCourseIds`: 교과과정표의 전공필수 7과목

**아직 확인하지 못한 것**

- 총 이수 학점·전공 최소 학점·학기당 최대 학점 (`requirements`의 `null` 항목)
- 학정번호 (`courseCodes`)
- 기초교양 과목(대학수학및연습 등)과 관련 선수 관계

## 데이터 작성 규칙

- 과목명 대신 고유한 과목 `id`로 관계를 연결합니다.
- 모르는 값은 추측하지 않고 `null`(미확인)로 둡니다. `[]`은 "확인했는데 없음"입니다.
- 실제 학교 자료를 검증하기 전까지 **가상 과목을 공식 데이터처럼 추가하지 않습니다.**
- 형식을 바꿔야 하면 팀원과 합의한 뒤 계약서를 먼저 고칩니다.
