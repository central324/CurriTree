# 교육과정 데이터

`data/curricula/` 폴더의 JSON 파일 하나가 교육과정 하나입니다. 서버는 시작할 때 이 폴더를 읽고 아래 API로 제공합니다.

| API | 내용 |
| --- | --- |
| `GET /api/departments` | 학과 목록과 학과별 교육과정 목록 |
| `GET /api/curriculum/:dept` | 학과의 기본 교육과정 JSON (`?curriculumId=`로 선택 가능) |

형식은 `docs/CONTRACT_CHECKLIST.md` 2절을 따릅니다. 계약을 어긴 파일이 하나라도 있으면 서버 로그에 오류가 표시되고 조회 API는 500을 반환합니다. `npm test`로 미리 확인할 수 있습니다.

## 현재 등록된 교육과정

### `ce-2023.json` — 컴퓨터정보공학부 (2023학년도 기준, 2022,2023학번 적용)

- 과목·학기·이수구분·학점: [교과과정표(2023학년도)](https://ce.kw.ac.kr/program/process.php) 42과목·113학점. 과거 과목명은 `aliases`
- `공학설계입문`: 표에는 없지만 이수체계도의 필수 선수(→ 객체지향프로그래밍설계)라 포함. 권장 학기는 공학인증 공학주제 교과과정표의 개설학년 `1-1/1-2`에 따라 학년만(`"1"`) 표기. 2022학년도 1학기부터 전공선택으로 이수구분이 변경된 공식 자료 확인 `major_elective`, 학점 3
- 선수·연계 관계: [이수체계도](https://ce.kw.ac.kr/engineering_certify/subject.php)
  - `hardPrerequisiteIds`: 필수 선후수(빨간 화살표). 체계도에 없거나 선수 과목이 데이터에 없으면 `null`
  - `recommendedPreviousIds`: 추천 선후수(검은 화살표) + 같은 과목명 1 → 2
  - `linkedCourseIds`: 설계(이론)↔실습·실험 짝 5쌍
- 진로 트랙 태그: 26년 전공 로드맵의 3개 트랙 (로드맵에 없는 `인공지능프로그래밍`은 `[]`)
- `requiredCourseIds`: 교과과정표의 전공필수 7과목
- 졸업 학점: [입학연도별 졸업학점 안내](https://www.kw.ac.kr/ko/life/bachelor_info12.jsp)의 2020~2023학년도 입학자 표, 컴퓨터정보공학부 행 (2026-11-17 확인)
  - `minimumTotalCredits`: 133 (졸업이수학점)
  - `minimumMajorCredits`: 60 (단일전공 기준 주전공 학점, 전필+전선 합계. 다전공 이수 시 54학점은 아직 반영하지 않음 → 커리메이커 이수요건 검증에 "단일전공 기준" 안내 표시)

- 학정번호(`courseCodes`, 분반 제외) 35과목: 학교 **2026학년도 1·2학기 개설과목 강의시간표**에서 컴퓨터정보공학부(`I020`)가 같은 과목명으로 개설한 과목 (2026-11-17 확인)
  - 출처: 광운대 공지사항 [2026학년도 1학기 수강신청자료집](https://www.kw.ac.kr/ko/life/notice.jsp?BoardMode=view&DUID=51714), [2026학년도 2학기 수강신청자료집](https://www.kw.ac.kr/ko/life/notice.jsp?BoardMode=view&DUID=52981)의 첨부 강의시간표(인공지능융합대학 공통·컴퓨터정보공학부 쪽). 학정번호는 분반(`-01` 등)을 뺀 앞 세 부분만 저장
  - `공학설계입문`은 개설학과 '공통'의 학정번호 2개(`I000-1-2957`, `7000-1-2957`)
  - **동일교과목 등록현황**에 따라 현재 개설명의 학정번호와 별칭을 등록: `전자회로`↔`디지털전자회로`(5465), `지능IoT특론`↔`지능IT특론`(5469), `무선이동네트워크및5G`↔`무선모바일네트워크`(5466)
  - 다른 학과가 같은 이름으로 개설한 과목(예: 전자공학과 `컴퓨터구조`)의 학정번호는 넣지 않음
  - 2026-1 `산학협력캡스톤설계`(`I020-4-5467`)는 동일교과목상 캡스톤설계1·2 모두와 연결되어 어느 과목인지 정할 수 없어 넣지 않음
  - `GPU컴퓨팅`은 교과과정표상 3-2지만 2026년에는 1학기(`I020-4-9615`)에 개설됨. 권장·개설 학기는 교과과정표 기준 유지

#### 2022학번 적용 범위 확대 (#55)

2022학번과 2023학번에 공통으로 적용되는 졸업요건을 확인하여
기존 2023학년도 기준 교육과정의 적용 입학년도 범위를 확대합니다.

- `curriculumId`: `ce-2023` 유지
- `catalogYear`: 2023 유지
- `admissionYears`: `[2022, 2023]`
- 총 등록 교과목: 46개

| 항목 | 2022학번 | 2023학번 |

##### 과거 이수내역 처리

- 기존 교과목의 과거 명칭은 `aliases`를 활용하여 매칭합니다.
- 이수 완료 과목은 KLAS에서 전달된 실제 취득 학점(`earnedCredits`)을 사용합니다.
- 수강 중 및 수강 예정 과목은 교육과정 JSON에 등록된 학점을 사용합니다.
- 과거 교양으로 이수한 기록은 KLAS의 이수구분을 유지합니다.
- 기존 수강 계획 JSON 계약 및 학점 계산 규칙은 변경하지 않습니다.

##### 적용 범위 및 제한사항

- 2023학년도 기준 교과과정표와 이수체계도를 공통으로 사용합니다.
- 2022학년도 전체 교과과정표 및 당시 선수 관계를 독립적으로 재구성한 것은 아닙니다.
- 컴퓨터공학입문세미나, 데이터구조실습은 공식 자료 간 학점 차이가 존재하므로 실제 취득 학점을 확인해야 합니다.
- Human Computer Interaction 등 과거 교과목의 개설 및 인정 범위는 추가 확인이 필요합니다.
- 모든 과거 학정번호 및 폐지 교과목의 매칭을 보장하지 않습니다.
- 실제 졸업요건은 학교 공식 학사 자료를 기준으로 최종 확인해야 합니다.

## 데이터 작성 규칙

- 과목명 대신 고유한 과목 `id`로 관계를 연결합니다.
- 모르는 값은 추측하지 않고 `null`(미확인)로 둡니다. `[]`은 "확인했는데 없음"입니다.
- 실제 학교 자료를 검증하기 전까지 **가상 과목을 공식 데이터처럼 추가하지 않습니다.**
- 형식을 바꿔야 하면 팀원과 합의한 뒤 계약서를 먼저 고칩니다.
