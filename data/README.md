# 교육과정 데이터

`data/curricula/` 폴더의 JSON 파일 하나가 교육과정 하나입니다. 서버는 시작할 때 이 폴더를 읽고 아래 API로 제공합니다.

| API | 내용 |
| --- | --- |
| `GET /api/departments` | 학과 목록과 학과별 교육과정 목록 |
| `GET /api/curriculum/:dept` | 학과의 기본 교육과정 JSON (`?curriculumId=`로 선택 가능) |

형식은 `docs/CONTRACT_CHECKLIST.md` 2절을 따릅니다. 계약을 어긴 파일이 하나라도 있으면 서버 로그에 오류가 표시되고 조회 API는 500을 반환합니다. `npm test`로 미리 확인할 수 있습니다.

## 현재 등록된 교육과정

### `ce-2026.json` — 컴퓨터정보공학부

- 과목·학기·이수구분·학점: **공학주제 교과과정표** (43과목, 합계 115학점)
- 진로 트랙 태그: **컴퓨터정보공학부 전공 로드맵**의 3개 트랙
- 선수 관계: 로드맵에 "선·후수과목 없음", "추천 유관과목 없음"으로 표기되어 `[]`
- `공학설계입문`은 학번(홀수·짝수)에 따라 1학기 또는 2학기에 이수하므로 `recommendedTerm: null`, `offeredTerms: ["1", "2"]`
- `requiredCourseIds`: 편성표의 전공필수(전필) 6과목

**아직 확인하지 못한 것 (확인 후 `isDemo: false`로 변경)**

- 공식 자료 출처 URL과 확인 날짜 (`source.url`, `source.verifiedAt`)
- 적용 입학년도 (`admissionYears`) — 현재 2026으로 임시 기록
- 총 이수 학점·전공 최소 학점·학기당 최대 학점 (`requirements`의 `null` 항목)
- 학정번호 (`courseCodes`)

## 데이터 작성 규칙

- 과목명 대신 고유한 과목 `id`로 관계를 연결합니다.
- 모르는 값은 추측하지 않고 `null`(미확인)로 둡니다. `[]`은 "확인했는데 없음"입니다.
- 실제 학교 자료를 검증하기 전까지 **가상 과목을 공식 데이터처럼 추가하지 않습니다.**
- 형식을 바꿔야 하면 팀원과 합의한 뒤 계약서를 먼저 고칩니다.
